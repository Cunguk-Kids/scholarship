# Skoolchein Protocol Implementation Checklist (v4.0.2)

This checklist tracks the **Gas & Security Optimizations** identified during the V4 protocol audit. These changes are critical for mainnet readiness and scalability.

---

## 🟢 Phase 4: Protocol Hardening (ACTIVE)

_Status: Core Refactor Complete_

### 1. Gas Optimizations (Cost Reduction)

- [x] **Type Refactoring**: Change `string provider` and `string externalId` to `bytes32` in the `Milestone` struct.
- [x] **Struct Packing**: Reorder `Scholar` and `VoterInfo` structs to pack variables into fewer 32-byte slots.
- [x] **Completion Logic**: Replace the O(n) loop in `_checkProgramCompletion` with a simple `completedScholarCount` counter.
- [ ] **Financial Packing**: Review `uint256` usage for counters (like `applicantCount`) and downscale to `uint32/uint48` where safe.

### 2. Security & Scalability (Safety)

- [ ] **Batch Resolution**: Refactor `resolveShortlist` to support multi-transaction batching (essential for >100 applicants).
- [ ] **Anti-Griefing**: Implement a dispute window extension/buffer in `ScholarshipBounty.sol` to prevent last-minute frontrunning.
- [x] **Participation Guards**: Add explicit `openDonation` checks to the `_placeConfidenceStake` internal function.
- [ ] **Reentrancy Review**: Fine-tune the `nonReentrant` usage in `MilestoneManager` vs `ScholarshipCore` to ensure no "gas-reentrancy" bloat.
