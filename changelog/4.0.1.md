# Skoolchein Protocol Implementation Checklist

This checklist tracks the development of the **External Learning Bridge** and **Public Participation Controls**.

---

## 🟢 Phase 1: Metadata-Only Bridge (COMPLETED)

_Status: Verified via Webhooks & Dashboard Sync_

- [x] **IPFS Naming Standard**: Enforced `skoolchein-[service]-[id]` prefixing across the stack.
- [x] **Student Identity**: Added "HackQuest ID" to the `ApplyPage.tsx` and IPFS metadata.
- [x] **Ponder Webhook**: Created a secure endpoint to receive platform progress updates.
- [x] **Dashboard Sync (Initial)**: Added a "Sync with HackQuest" button with hardcoded detection.

## 🟢 Phase 2: On-Chain Protocol Controls (COMPLETED)

_Status: Verified on local node & Ponder Sync_

- [x] **Milestone Struct**: Add `provider` and `externalId` to `ScholarshipTypes.sol`.
- [x] **Program Struct**: Add `openDonation` (bool) to `ScholarshipTypes.sol`.
- [x] **Voting Governance**: Implement `openDonation` check inside `voteForCandidate`.

- [x] **Deep Indexing**: Update `schema.ts` to track new on-chain fields.
- [x] **Real-time API**: Expose `openDonation` and `milestone.provider` via GET endpoints.

### 3. Frontend (Creator UI)

- [x] **Link to Platform**: Add "External Provider" inputs to the winner selection modal.
- [x] **Privacy Toggle**: Add "Allow Public Participation" switch in the program management flow.

### 4. Frontend (Student UI - Autodetect)

- [x] **Smart Sync Button**: Remove hardcoded checks; use `milestone.provider` to show/hide Sync UI.
- [x] **Dynamic Labels**: Update button to `Sync with ${milestone.provider}`.
