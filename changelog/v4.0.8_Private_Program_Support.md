# Skoolchein Protocol v4.0.8 — Private Program Support & Batching

## 🗳️ Governance & Scalability

Implementing mission-critical support for private, initiator-funded programs and industrial-scale shortlist resolution. This release ensures the protocol can handle thousands of applicants while allowing for a streamlined bypass of public participation when `openDonation` is disabled.

- [x] **Private Program Bypass (Phase 6.6)**:
  - [x] **Contract Logic**: Update `_selectWinners` in `ScholarshipCoreBase.sol` to bypass `VotingNotEnded` and `QuorumMet` checks if `openDonation` is `false`.
  - [x] **State Transition**: Ensure `resolveShortlistBatch` allows programs to skip the public voting period when participation is restricted.
  - [x] **Frontend Awareness**: Update `ProgramDetailPage.tsx` and `Dashboard` to reflect the "Skip to Selection" flow for private programs.

- [x] **Industrial Scale Batching (Phase 8.1)**:
  - [x] **UI Integration**: Update `ResolveShortlistModal.tsx` to use the `useResolveShortlistBatch` hook.
  - [x] **Sequential Signing**: Implement a "multi-transaction" UX that segments large applicant pools into segments of 50.
  - [x] **Progress Tracking**: Ensure the initiator can resume a partially completed batch resolution.

- [ ] **Phase 3: Advanced Integrations (CARRIED OVER)**:
  - [ ] **Udemy/Dicoding Webhooks**: Implement platform-specific parsing in the controller.
  - [ ] **Sertifikat Verification**: IPFS verification of completion certificates.

- [x] **Protocol Parity & Optimization (Phase 2)**:
  - [x] **PID Standardization**: Rename all `programId` parameters to `pid` across all 4.x protocol contracts and interfaces for gas efficiency and consistent EIP-170 compliance.
  - [x] **Bytecode Optimization**: Move the implementation of administrative logic from `ScholarshipCoreBase.sol` to `ScholarshipAdmin.sol` to keep the main core contract under the 24KB limit.
  - [x] **Role Migration**: Implement `CONFIG_ADMIN_ROLE` for restricted access between `ScholarshipAdmin` and `ScholarshipCore`.
  - [x] **Interface Update**: Standardize `IScholarship.sol` to match the new `pid` variable names for unified cross-contract communication.

## 🚦 Security Standards

- [x] Strictly enforce `onlyInitiator` on batch resolution segments.
- [x] Maintain `openDonation` as the master gate for all public `VoteCast` and `ConfidenceStaked` activity.

The following features were identified as out-of-scope for the v4.0.7 synchronization but remain on the roadmap:

  - [ ] Manual `addYield` remains the primary mechanism for v4.

- [ ] **Industrial Scale Voter Distribution**:

- [ ] **Udemy/Dicoding Webhooks**: Implement platform-specific parsing in the controller.
